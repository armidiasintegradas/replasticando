# Replasticando — Website Institucional & Catálogo de Engenharia

Plataforma oficial da Replasticando desenvolvida a partir dos designs homologados no Stitch.

## Estrutura do Workspace

- `/docs`: Documentação normativa de engenharia, governança de conteúdo e QA.
- `/references/stitch-originals`: Códigos-fonte de referência (Visual Source of Truth) recuperados do Stitch.
- `/assets`: Repositório de ativos categorizados (`official`, `real`, `conceptual`, `pending`).
- `/src`: Código-fonte da aplicação (componentes, layout, dados, estilos).
- `/reports/qa`: Relatórios de auditoria visual e baterias de teste.
